## Interaction Contracts

### Assessment Step Screen

1. User arrives at a dimension screen showing:
   - Dimension name (Heading, 20px/600)
   - Dimension prompt/description (Body, 16px/400) — 2-4 sentences max
   - Slider (full-width, 44px touch target, accent-colored thumb and filled track)
   - Numeric readout displaying current value as "NN%" positioned above or beside slider thumb, always visible
   - Progress indicator: text label "Step N of 5" (Label, 14px/400) positioned top-center
   - "Back" button (secondary/ghost variant) — disabled on step 1
   - "Next" button (primary/accent variant) — advances to next dimension

2. Slider behavior:
   - Default value on first visit to a dimension: 50 (midpoint)
   - If user navigates back to a previously scored dimension: restore their saved value
   - Continuous range 1-100, no step increments (D-02)
   - Numeric readout updates live as slider moves

3. Progress indicator:
   - Text: "Step N of 5" (e.g., "Step 2 of 5")
   - Visual: 5 dots or a filled bar showing N/5 completion
   - Active step uses accent color; completed steps use accent at 60% opacity; future steps use border color

4. Navigation:
   - "Next" on step 5 triggers save to IndexedDB and navigates to summary screen
   - "Back" navigates to previous dimension and restores that dimension's last set value
   - No confirmation required to navigate back (non-destructive)

### Summary Screen

1. After completing all 5 dimensions, user sees:
   - Heading: "Your Peace Index" (Display, 28px/600)
   - Subheading: date of assessment formatted as "April 13, 2026" (Label, 14px/400, text-secondary)
   - 5 score cards, one per dimension, stacked vertically (mobile) or 2-column grid (desktop/tablet)
   - Each card shows: dimension name (Heading, 20px/600), score value as "NN%" (Display, 28px/600, accent color)
   - "Start New Assessment" CTA button below cards

2. Score card layout (per card):
   - Background: secondary (#F8FAFC)
   - Border: border color (#E2E8F0), 1px, rounded-lg (8px radius)
   - Padding: 16px (md)
   - Dimension name: top-left, Heading
   - Score: bottom-right or centered below name, Display size, accent color

## Transition Contract

| Transition | Behavior |
|------------|----------|
| Dimension step advance (Next) | Slide left — outgoing screen slides out to left, incoming slides in from right. Duration: 200ms ease-in-out. |
| Dimension step back (Back) | Slide right — outgoing slides out to right, incoming slides in from left. Duration: 200ms ease-in-out. |
| Step to summary | Fade in — summary fades in over 300ms after save completes. |
| Numeric readout update | No animation — live text update only, no number-count animation. |

Implementation: use Tailwind CSS transition utilities or CSS custom properties. Do NOT use a third-party animation library for Phase 1.

## Layout Contract

| Breakpoint | Layout |
|------------|--------|
| Mobile (< 640px) | Single column, full-width card, 32px horizontal page padding |
| Tablet (640-1024px) | Single column centered, max-width 560px, auto margins |
| Desktop (> 1024px) | Single column centered, max-width 560px, auto margins |

The assessment flow is single-column on all screen sizes. The summary screen uses a 2-column card grid at tablet and above (2 cols for 4 dimensions + 1 full-width for 5th, or keep single column — single column is acceptable for Phase 1).

Page structure (top to bottom):
1. App bar: "Peace Index" app name (Display, left-aligned) — height 56px
2. Progress indicator: "Step N of 5" — 24px top margin from app bar
3. Content area: dimension card (centered, fills remaining height)
4. Navigation row: Back + Next buttons — fixed to bottom of content area or naturally at card bottom
